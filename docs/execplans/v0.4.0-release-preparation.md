## Purpose / Big Picture

Industry Momentum is implemented and merged into `main`, but the repository still identifies the installed package and published release as `0.3.0`. This slice converts the merged feature into a truthful, version-aligned, exactly validated `v0.4.0` release candidate and then, only after separate owner authorization, publishes an annotated immutable tag and GitHub Public Beta release.

## Surprises & Discoveries

- Observation: The implementation merge is healthy and has passing post-merge CI and Docker evidence, but every authoritative package-version surface intentionally remains at `0.3.0`.
  Evidence: `pyproject.toml`, Commitizen metadata, `src/version.py`, and `tests/test_release_version.py` all matched `0.3.0` before this branch.
- Observation: The existing release-version regression covered the original Industry Pulse generator identity but not the CES and G.17 generator user agents added by Industry Momentum.
  Evidence: both Momentum generators import `src.version.__version__` and send it in official-provider request headers; the release test covered only `generate_industry_pulse_snapshot`.
- Observation: Open PRs #117, #121, #122, and #131 are unrelated to the release candidate and were created from the pre-Momentum base.
  Evidence: their branches diverge from current `main`; merging or rebasing them into this release slice would expand risk and invalidate a focused release review.

## Idempotence and Recovery

Version and documentation edits are deterministic and may be repeated from the known starting SHA. Do not rewrite history, force-push, reset, clean, or discard work to recover. If the branch moves unexpectedly, the disposable checkout is dirty, or protected state is ambiguous, stop and report the exact state.

A failed test or acceptance item must produce a correction commit followed by a complete exact-head rerun. Do not reuse older evidence after the candidate head changes.

No tag or release action is recoverable through moving an existing published tag. If publication fails after the annotated tag is created, preserve the tag, diagnose the release operation, and resume without force-moving the tag.
