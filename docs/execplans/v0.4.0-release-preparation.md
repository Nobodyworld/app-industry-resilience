## Purpose / Big Picture

Industry Momentum was implemented, aligned at version `0.4.0`, exactly validated, squash-merged into `main`, and published as the `v0.4.0 Public Beta — Industry Momentum` GitHub prerelease after separate merge and publication authorizations. This plan preserves the preparation, validation, authorization, publication, and parity evidence for that completed release lifecycle.

The release preserves the established product boundary: monthly PPI, CES, and Federal Reserve G.17 observations remain contextual and never alter annual ratios, rankings, Scenario Lab, health scores or bands, or annual lineage. Publication introduced no new providers, mappings, analytics, scoring, API versions, dependency upgrades, or CI redesign.

## Concrete Steps

Run local commands only in a disposable checkout/worktree created for this slice. Treat the primary checkout and all pre-existing workspaces, stashes, ignored content, and unrelated branches as protected.

    python -m pytest -q tests/test_release_version.py

## Idempotence and Recovery

Version and documentation edits are deterministic and may be repeated from the known starting SHA. Do not rewrite history, force-push, reset, clean, or discard work to recover. If the branch moves unexpectedly, the disposable checkout is dirty, or protected state is ambiguous, stop and report the exact state.

A failed test or acceptance item must produce a correction commit followed by a complete exact-head rerun. Do not reuse older evidence after the candidate head changes.

No tag or release action is recoverable through moving an existing published tag. If publication fails after the annotated tag is created, preserve the tag, diagnose the release operation, and resume without force-moving the tag.
